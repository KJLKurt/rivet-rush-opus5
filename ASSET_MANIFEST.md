# Asset Manifest

Every asset in this game was created during this project. There are **no binary
art or audio files in the source tree** — the only images shipped are the PWA
icons and store screenshots, and both are generated by scripts in `scripts/`.

See [`THIRD_PARTY_ASSETS.md`](THIRD_PARTY_ASSETS.md) for licensing (short version:
nothing external was used).

---

## 1. 3D models — procedural geometry

All models are assembled at runtime from Three.js primitives (rounded boxes,
spheres, capsules, cylinders, torii, cones, lathes, icosahedra). Static
sub-assemblies are merged per material with `mergeGeometries`, so a prop is
normally one to three draw calls. 1 world unit ≈ 1 metre; Rivet is ~1.4 units.

### Characters — `src/render/models/`

| Asset | File | Notes |
| --- | --- | --- |
| **Rivet** | `Rivet.ts` | Chibi raccoon: bandit mask, cream muzzle, ringed bushy tail, welding goggles pushed up on his forehead, orange scarf. Fully procedural animation — banking, lean, hover bob, squash-and-stretch, arm swing, ear twitches, blinking, eyebrow expressions. The tail and scarf are two-DOF spring chains driven by his own motion. |
| **Hoverboard** | `Rivet.ts` | Chamfered deck, magnetic coil rings, an emissive underglow plate that swells on dash. Six colour skins. |
| **Sparkie** | `Sparkie.ts` | One big friendly eye under a glass dome, bobbing antenna, hover fins, thruster glow. Four moods (trapped / freed / following / cheering) driven by brightness, bob rate and fin flutter. |
| **Buzzbot, Sawdrone, Zapper, Bomblet, Shieldbot** | `Enemies.ts` | Five silhouettes distinguishable at a glance, in a shared violet/magenta hostile palette with hard white eyes. Per-kind idle, chase, telegraph, attack and stunned poses, plus a bouncing scrap-burst defeat effect. |
| **Skitter, Lobber, Splitter, Snatcher, Warden** | `EnemiesExtra.ts` | Five more, added for Swarm mode. A flat four-legged crawler with an animated tripod gait, a mortar with an elevating recoiling barrel, a clamped pod that splits, a claw-handed thief with a containment cage, and a haloed support drone with a scalable aura. ## 2. Textures — procedural canvas

Generated once on first use by `src/render/Textures.ts`, drawn into a `<canvas>`
and wrapped in `THREE.CanvasTexture`. Cached by key; 128–512 px.

**Tiling surfaces:** `metalPanel` (brushed plate with rivets and scratches),
`metalPlate` (diamond tread), `rustPanel`, `hazardStripe` (amber/black chevrons),
`grassTop`, `rockSide`, `circuit`, `gridGlow`, `woodPlank`.

**Sprites:** `cloudSprite`, `glowSprite`, `sparkSprite`, `ringSprite`,
`smokeSprite`, `shadowBlob`.

**Data:** `noise`, and the `toonRamp3` / `toonRamp4` / `toonRampSoft` gradient
maps that give the cel shading its steps.

## 3. Materials and shaders

- `src/render/Materials.ts` — cached `MeshToonMaterial` factory, additive glow
  materials, billboard sprite materials, a proper rounded-box geometry generator,
  and inverted-hull outlines that offset along the view-space normal so the ink
  line stays a constant width at any scale.
- Hand-written GLSL: the sky dome gradient (`Sky.ts`), the magnetic fence
  (`Arena.ts`), the particle point-sprite shader and the hoverboard trail ribbon
  (`Fx.ts`, `Trail.ts`), and the full-screen grade pass — vignette, saturation,
  radial speed blur and colour wash (`Renderer.ts`).

## 4. Audio — Web Audio synthesis

`src/core/Audio.ts`. No audio files, no samples. Every sound is built from
oscillators, filtered noise buffers and envelopes at runtime.

**Sound effects (~40):** UI move / confirm / back / unlock / toggle; bolt, cell,
Sparkie rescue, Sparkie chirp, heart, crate smash; dash, dash-fail,
dash-recharge, boost pad; zap, chain zap, enemy hit / defeat / attack /
telegraph; player hurt, shield gain / break; combo up, combo break, Overdrive
ready / start / end; upgrade show / pick; portal open / enter; boss intro / slam /
hurt / phase / defeat; victory, game over, countdown, score tally, star.

Design notes: the bolt sound is pitched by combo tier so chaining pickups plays a
melody up the major pentatonic; repeated effects carry ±3% random detune so they
never sound machine-gunned; the damage sound is a soft bonk rather than anything
harsh.

**Music — six original tracks**, composed as note data (chord progressions,
basslines, melodies, drum patterns) and played through synth voices (pluck, bass,
lead, pad, bell, plus drums synthesized from noise and pitched sines):

| Track | Tempo | Character |
| --- | --- | --- |
| `menu` | ~100 BPM | Warm, hopeful, pad and bells |
| `area1` | ~124 BPM | Bouncy major-key adventure |
| `area2` | ~128 BPM | Airier, Lydian colour, swung hats |
| `area3` | ~136 BPM | Driving, dorian, urgent |
| `boss` | ~142 BPM | Heroic, syncopated, brass-ish stabs |
| `victory` | — | Short triumphant loop |

Tracks share a key family and motif fragments so the soundtrack reads as one
score. Layers mute and unmute with `setMusicIntensity` as the player's combo
rises, Overdrive adds an octave-up doubled lead, and track changes crossfade on a
bar boundary.

## 5. Interface art

| Asset | Source |
| --- | --- |
